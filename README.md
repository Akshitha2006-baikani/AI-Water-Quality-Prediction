# AI Water Quality Analysis and pH Prediction

## 1. Project Overview

This project uses machine learning to analyze historical water-quality measurements
and predict the next-day normalized pH value at monitoring locations.

The system uses water-quality measurements from multiple monitoring locations and
applies machine-learning techniques to identify patterns associated with next-day pH.

---

## 2. Objective

The objectives of this project are:

- Analyze historical water-quality data.
- Perform exploratory data analysis.
- Predict next-day normalized pH values using machine learning.
- Compare Linear Regression and Random Forest Regression models.
- Evaluate model performance using MAE, RMSE and R-squared.
- Identify important water-quality features using Random Forest feature importance.
- Generate visualizations and prediction results for analysis.

---

## 3. Dataset

The processed dataset contains:

- 26,048 records
- 37 monitoring locations
- 14 columns
- 13 input features
- 1 target variable
- 0 missing values

### Target Variable

`target_ph_next_day`

The target represents the next-day normalized pH value associated with each
monitoring location.

> Note: The target values in the processed dataset are normalized values.
> They should not be interpreted as direct pH measurements without the original
> normalization parameters.

### Input Features

- `date_index`
- `location_id`
- `specific_conductance_max`
- `ph_max`
- `ph_min`
- `specific_conductance_min`
- `specific_conductance_mean`
- `dissolved_oxygen_max`
- `dissolved_oxygen_mean`
- `dissolved_oxygen_min`
- `temperature_mean`
- `temperature_min`
- `temperature_max`

6. Machine Learning Models

Two regression models were evaluated in this project.

Linear Regression

Linear Regression was used as a baseline model for comparison.

Random Forest Regression

Random Forest Regression was used to model nonlinear relationships between
water-quality measurements and next-day normalized pH.

The Random Forest model was trained using 30 decision trees with
random_state=42.

7. Model Performance

The models were evaluated using an 80/20 train-test split with
random_state=42.

Linear Regression
MAE: 0.021581872
RMSE: 0.029506618
R-squared: 0.000270255
Random Forest Regression
MAE: 0.006949124
RMSE: 0.013180087
R-squared: 0.800528753

The Random Forest model achieved stronger performance than the Linear Regression
baseline on the test dataset used in this experiment.

8. Feature Importance

Random Forest feature importance was calculated to identify which input

The most important feature in this experiment was:

dissolved_oxygen_max

Importance:

0.725222

prediction. It should not be interpreted as a causal relationship.
